PAVY Shala Website – V62 Complete Website Package

This package consolidates the approved static HTML website prototype and includes the updated Cooking Class page and expanded teacher biographies.

Included pages:
- Home page
- About page with expanded Sheshadri (Founder) and Harish (Director) biographies
- Ashtanga Yoga Mysore Style course page
- Pranayama course page
- Teacher Training Course (TTC) page
- Certification Course page
- Yoga Sutra Chanting with Explanation page
- Cooking Class page using the information from the existing PAVY Shala cooking page
- Schedule page
- Contact page with address, phone, email, Google Maps and WhatsApp enquiry flow
- Blog and Student Feedback page with Google Reviews link
- Shared styles and image assets

Cooking Class content:
- Cooking classes are available with Bharathi Sheshadri on request.
- Classes can be personalised to the visitor's interests.
- Visitors can use the Contact page enquiry section to make arrangements.

Teacher biographies:
- Biographies are presented in expandable sections to keep the About page readable.
- The content is based on details supplied by the site owner; please verify institution names, awards and qualification titles before publication.

Important deployment note:
- This is a static HTML/CSS/JavaScript website package, not yet a WordPress theme or connected CMS.
- It can be reviewed as a prototype, but before publishing to the primary domain, test navigation, forms, external links, mobile layout and all pages.
- The custom CMS still needs to be implemented and connected. Do not overwrite the existing live site without making a full backup and confirming the deployment plan.
